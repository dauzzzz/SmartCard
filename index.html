Firebase Firestore Security Rules (firestore.rules)

Salin aturan keamanan ini ke menu Firestore Database → Rules di Firebase Console Anda.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /peserta/{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /pengaturan/{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

Sistem otomatis menaikkan angka atau tingkat kelas seluruh siswa sebanyak +1 tingkat tanpa perlu mengedit satu per satu:
• SD/MI: 1 → 2, 2 → 3, ..., 5 → 6 (termasuk 1A → 2A)
• SMP/SMA: 7 → 8, VII → VIII, X MIPA 1 → XI MIPA 1
